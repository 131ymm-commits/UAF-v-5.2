# PROTOCOL.md — Рабочий протокол UAF v5.2

**Читать первым. Эти правила не обсуждаются — они защищают непрерывность работы.**

---

## ⚠ ПРАВИЛО 1 — ДВА ФАЙЛА ВСЕГДА

Каждый эксперимент ВСЕГДА производит ДВА файла. Без исключений.

```
experiments/exp_NNN_qXX.py      ← код
reports/exp_NNN_qXX_report.md   ← отчёт
```

**Почему критично:** контекст между итерациями теряется. Код без отчёта =
потерянная работа (новая итерация не знает, что и зачем сделано). Отчёт без
кода = невоспроизводимо. Только оба вместе сохраняют исследование.

Отчёт ОБЯЗАН начинаться с блока «Контекст для новых итераций»:
- серия EXP одной строкой
- ключевые числа предыдущих находок
- текущий вопрос

---

## ⚠ ПРАВИЛО 2 — MAIN CHAT — ЕДИНСТВЕННЫЙ КАНАЛ ИНТЕГРАЦИИ

Окончательная нумерация и внесение в репозиторий — право ТОЛЬКО main-чата.

Сторонние чаты (параллельные окна) могут вести черновую работу, но их
результаты интегрируются в репозиторий ТОЛЬКО через main. Это устраняет
проблему v5.1 (пропущенные/задвоенные номера из параллельных окон).

Поток данных:
```
   сторонний чат → черновик → MAIN → нумерация → репозиторий
   сторонний чат ─┘
```

Никакой прямой записи в репозиторий из сторонних чатов.

## ПРАВИЛО 5 — ВЕРДИКТ ОБЯЗАТЕЛЕН

Каждый валидационный эксперимент завершается явным вердиктом:
- `ДЕРЖИТСЯ` — отклонение < 5%, инвариант подтверждён вне модели
- `ЧАСТИЧНО` — отклонение 5–20%, есть поправка
- `НЕ ДЕРЖИТСЯ` — отклонение > 20%, инвариант был артефактом

NPG ≤ 0 → отклонить модель в этом домене. Всегда.

---

## ПРАВИЛО 6 — ИМПОРТ, НЕ КОПИРОВАНИЕ

Проверенные функции живут в `uaf/`. Эксперименты их ИМПОРТИРУЮТ,
не копируют. Если функция переписывается в каждом эксперименте —
расхождения накапливаются. Один источник истины = `uaf/`.

Новую проверенную функцию → добавить в соответствующий модуль `uaf/`.

---

## ПРАВИЛО 7 — ЧЕСТНОСТЬ ВМЕСТО ЭЙФОРИИ

- Никакого «Nobel Prize» framing. UAF — интересный фреймворк, не закон.
- При расхождении симуляции и аналитики — копать, не замазывать.
- Численные тесты: осторожный выбор начальных условий
  (урок Q18: A0 далеко от A*_eff не ловит эффект).
- Отрицательный результат — полноценный результат.
