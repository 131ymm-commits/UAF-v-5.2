# UAF v5.2 — EXP 023 / Q23
# Операционализация: извлечь het из динамики A(t) без топологии

## Контекст для новых итераций

**Серия v5.2 одной строкой:**
ФАЗА 1 (ABM ✓) → **ФАЗА 2 (операционализация)** → ФАЗА 3 (реальные данные)

**Фаза 1 завершена:**
```
χ·A*_uns = (δ/α_s)·het^(−0.22), het=<k²>/<k>²
Подтверждено на BA/ER/WS/regular + реальном коннектоме C. elegans (−2.2%)
```

**Q23 — мост Фазы 2:** реальные данные дают A_i(t), но НЕ матрицу связей.
Можно ли извлечь het из динамики? Если да — Фаза 3 возможна.

---

## Результаты

### 023-A: Калибровка (переходный метод)

Физика: в гетерогенной сети хабы получают больше TSV → растут резко,
листья медленно. **Разброс скоростей роста кодирует het.**

Наблюдаемая: `rise_rate_cv` = CV(макс. dA_i/dt по агентам в переходе).

| Сеть | het_true | rise_rate_cv |
|------|----------|--------------|
| Reg(k4) | 1.000 | 0.072 |
| ER(k6) | 1.156 | 0.275 |
| BA(2) | 2.054 | 0.653 |
| BA(6) | 1.676 | 0.586 |

```
het = 1.526·rise_rate_cv + 0.855    (R²=0.935)
```

### 023-B: Контроль — равновесный метод не работает

Флуктуации на верхнем аттракторе: r=0.31, R²=0.09.
На аттракторе агенты насыщены → информация о het теряется.
**Вывод: нужен переходный режим, не стационарный.**

### 023-C: Реальный коннектом C. elegans

| | Значение |
|---|----------|
| Истинный het (топология) | 1.581 |
| Оценка het (динамика, 5 сидов) | 1.735 ± 0.001 |
| Ошибка оценки het | +9.7% |

### 023-D: Полный операционный цикл (ключевое)

```
Из динамики:  het_est=1.735 → χ·A* = 0.1432
Из топологии: het_real=1.581 → χ·A* = 0.1461
Ошибка операционного предсказания: −2.0%
```

**Ошибка het была +9.7%, но предсказание водораздела ошибается лишь на
−2%.** Формула Q21 содержит het в степени −0.22 — малая чувствительность
к ошибке оценки. Степенная зависимость с малым показателем гасит ошибку.

---

## Физическая интерпретация

Это решение проблемы операционализации — главного барьера перед
реальными данными. Топология (матрица связей) часто недоступна в реальных
системах: мы видим активность нейронов, цены, популяции, но не «провода».

Ключевое наблюдение: **динамика отдельных агентов несёт отпечаток их
положения в сети.** Хаб с высокой степенью получает больше входного
сигнала и реагирует быстрее/резче. Распределение скоростей реакции по
агентам — это «тень» распределения степеней, а значит и het.

Важно, что работает именно переходный режим. В стационаре (на аттракторе)
все агенты прижаты к потолку A≈1, и различия стираются. Нужно ловить
систему в движении — при росте, восстановлении после возмущения, отклике
на стимул. Это биологически естественно: стимул-ответные протоколы.

Устойчивость цикла к ошибке het — следствие того, что Q21-поправка слабая
(показатель −0.22). Даже грубая оценка het даёт точный водораздел.

## ВЕРДИКТ Q23: МОСТ ПОСТРОЕН

| Проверка | Результат |
|----------|-----------|
| het из переходной динамики | R²=0.93 (калибровка) |
| На реальном коннектоме | het-оценка +9.7% |
| Операционный цикл | предсказание водораздела −2.0% |
| Равновесный метод | НЕ работает (R²=0.09) |

Топология не обязательна — het читается из динамики A_i(t) в переходном
режиме. Это открывает Фазу 3.

**Ограничение:** метод требует наблюдать систему в переходе (рост,
восстановление). Чисто стационарные записи недостаточны.

## Статус и следующий вопрос

**Q23 ЗАКРЫТ. Мост операционализации построен.**

**Q24 (следующий) — снять ограничение переходного режима:**
Реальные записи часто в стационаре. Варианты:
- impulse response: возмутить систему, измерить отклик → het
- спектр кросс-корреляций флуктуаций → спектр лапласиана → het
- записи во время восстановления после стимула (стимул-ответ —
  биологически реалистично)

Если Q24 извлечёт het из стимул-ответа — это прямо применимо к реальным
нейронным записям (кальциевый имейджинг со стимуляцией).

**После Q24 — Фаза 3:** загруженные записи активности C. elegans.
Извлечь het из реальной динамики, предсказать устойчивость, сверить.
Это будет первая полная проверка UAF на реальных данных активности —
от сырого временного ряда до предсказания водораздела.

**Методологическая заметка:** именно ради этого моста ABM шёл первым.
Теперь у нас есть: (1) проверенный закон χ·A*=(δ/α_s)·het^(−0.22),
(2) способ измерить het из топологии, (3) способ измерить het из
динамики. Три независимых пути к одной величине — это хорошая
триангуляция перед выходом на реальные данные.
