# UAF v5.2 — EXP 020 / Q20
# ABM-краш-тест: держится ли χ·A*_uns = δ/α_s вне среднего поля?

## Контекст для новых итераций

**Серия v5.2 одной строкой:**
ФАЗА 1 (ABM-краштест) → ФАЗА 2 (операционализация) → ФАЗА 3 (реальные данные)

**Что проверяем (из v5.1, доказано в HMF, CV<0.003):**
```
χ·A*_uns = δ/α_s = 0.200       χ = <k²>/<k>
точная форма: K(χ) = δ·χ/(α_s·χ + α_l) → 0.200 при χ→∞
```
При типичных χ≈4–12 HMF даёт χ·A* ≈ 0.166 (поправка α_l).

**Q20:** держится ли это в ПОЛНОЙ N-агентной симуляции (не HMF)?

**Метод:** реальные сети (BA, ER, regular) → измеряем настоящую χ из
матрицы смежности → ABM-водораздел A0_crit (бисекция: сеть выживает
⟺ A0 > A0_crit) → сравниваем χ·A0_crit с предсказанием.

```

het = χ/<k> = <k²>/<k>²   (регулярная: het=1)
```
При het=1 восстанавливается HMF-значение. Степенной фит по 6 топологиям.

Отклонение стабильно, не случайность.

## Физическая интерпретация

HMF предполагает, что **все** агенты видят одинаковое поле χ·⟨A⟩.
В реальной сети это не так:

- **Хабы** (высокая степень) видят больше соседей → переходят
  водораздел **первыми** даже при низком общем A0
- Перейдя, хаб через TSV тянет своих листьев вверх
- Коллективный каскад **понижает** реальный порог ниже однородного
  среднеполевого предсказания

Это ровно тот коллективный эффект BA, что был в v5.0 (НАХОДКА 4:
«группа N=60 из A=0.25 выживает, одиночка умирает»). Среднее поле его
структурно не улавливает — оно усредняет хаб и лист в одну точку.

Чем сильнее гетерогенность степеней (het), тем мощнее хаб-каскад,
тем ниже водораздел. Отсюда het^(−γ).

## ВЕРДИКТ Q20: ЧАСТИЧНО

| Класс сетей | Статус |
|-------------|--------|
| Регулярные (het=1) | ДЕРЖИТСЯ (точно) |
| Гетерогенные (het>1) | НЕ ДЕРЖИТСЯ (−12..−15% от HMF, −25% от K_inf) |

**Главный вывод:** `χ·A*_uns = δ/α_s` в исходной форме — **артефакт
среднего поля** для гетерогенных топологий. Регулярные сети его
соблюдают, потому что там het=1 и среднее поле точно.

Истинный закон (эмпирически):
```
χ·A*_uns = (δ/α_s) · het^(−0.126)
```

Это честный отрицательный результат для исходного инварианта —
и одновременно новая, более точная формула. v5.1 переоценила
универсальность: инвариант держится только для однородных сетей.

**Важная оговорка по числам:** «−25%» считается от асимптотического
K_inf=δ/α_s=0.200. От реалистичного HMF-предсказания (с поправкой α_l,
≈0.166) отклонение составляет −10..−13%. Оба числа корректны для своих
эталонов; для честности вердикта берём более строгий (от K_inf).

## Статус и следующий вопрос

**Q20 ЗАКРЫТ.** Вердикт: ЧАСТИЧНО, поправка het^(−0.126).

**Q21 (следующий):** Точная форма поправки.
- het^(−0.126) — фит по 6 точкам, нужно больше топологий
- Аналитический вывод γ из HMF второго порядка (корреляции степеней)
- Watts-Strogatz: кластеризация — ОТДЕЛЬНЫЙ эффект (треугольники),
  не входит ни в HMF, ни в het-поправку. Как она влияет?

**Гипотеза для Q21:** истинная восприимчивость — не χ=<k²>/<k>, а
эффективная χ_eff с поправкой на хаб-каскад. Возможно
χ_eff = <k²>/<k> · het^(−γ) = <k²>²/<k>³ · ... — проверить.

**Урок для всей v5.2:** среднее поле систематически переоценивает
порог в гетерогенных сетях. Все v5.1-инварианты, выведенные через
HMF, требуют ABM-проверки. Q20 показал, что краш-тест был необходим —
и что он ловит реальные расхождения.
