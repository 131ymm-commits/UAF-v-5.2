# Кластеризация vs гетерогенность: что ломает инвариант?

## Контекст для новых итераций

**Серия v5.2 одной строкой:**
ФАЗА 1 (ABM-краштест) → ФАЗА 2 (операционализация) → ФАЗА 3 (реальные данные)

**Q20 нашёл:** инвариант χ·A*=δ/α_s НЕ держится для гетерогенных сетей.
```
χ·A0_crit = (δ/α_s)·het^(−0.13)    het = <k²>/<k>²
регулярные (het=1): точно;  BA (het≈2): −15%;  растёт с N
```

**Q21:** кластеризация C — отдельный эффект или нет? Уточнить γ.

**Метод:** Watts-Strogatz варьирует C при ~фиксированном het. Комбинируем
с BA (широкий het) и регулярными (het=1, высокая C) для развязки.

## Физическая интерпретация

Это физически правильный результат. Водораздел определяется тем, как
быстро **хабы** переходят порог и тянут листья — это вопрос **степеней**
(глобальная структура степенного распределения), а не локальных петель.

Треугольники (кластеризация) меняют локальную структуру связей, но не
меняют, кто является хабом и сколько у него соседей. Поэтому хаб-каскад,
управляющий водоразделом, к ним нечувствителен.

HMF был слеп к гетерогенности (усреднял хаб и лист) — это ошибка, которую
Q20 поймал. Но к кластеризации HMF безразличен **правильно**: она и не
должна влиять на водораздел в этой динамике.

## ВЕРДИКТ Q21

| Фактор | Статус |
|--------|--------|
| Гетерогенность het | ПОДТВЕРЖДЕНА (главный драйвер, γ≈0.22) |
| Кластеризация C | ОТКЛОНЕНА (доказано напрямую, 7× C → 0.3% эффект) |
| Масштаб хаба k_max | ОСТАЁТСЯ (вторичный, объясняет R²<0.9) |

Уточнённый закон вне среднего поля:
```
χ·A*_uns = (δ/α_s) · het^(−0.22) · [поправка на k_max]
```

γ уточнён с 0.13 (Q20, 6 точек) до **0.22** (Q21, 14 точек, R²=0.85).
Остаточный разброс — не кластеризация, а абсолютный масштаб хабов
(χ·A0 падает с N даже при фиксированном het — наследие Q20-B).

**Что это значит для теории:** инвариант v5.1 требует ДВУХ поправок
относительно HMF — степенную het^(−0.22) и вторичную по k_max. Это
делает «универсальную константу» δ/α_s справедливой строго только в
пределе однородных сетей. Для реальных гетерогенных структур —
систематическое отклонение, которое теперь параметризовано.
