## Ключевые инварианты (то, что тестируем)

```
χ·A*_uns = δ/α_s = 0.200        K_∞, топологический инвариант
χ·slope  = −16.61               инвариант наклона
χ = <k²>/<k>                    ненаправленные
χ = <k_in·k_out>/<k>            направленные
```

Точная формула (с поправкой α_l):
```
K(χ) = δ·χ/(α_s·χ + α_l)  →  δ/α_s при χ → ∞
A*_uns(f,χ,Π₀) = δ/(α_s·χ+α_l) − (16.61/χ)·f − c_Π·ΔΠ₀
```

## Слабые места v5.1 (мотивация v5.2)

1. **Всё на HMF.** Среднее поле предполагает древовидность сети
   (нет треугольников). Реальные сети кластеризованы.
2. **Аналитическая χ ≠ измеренная χ.** Для BA(200,3): аналитическая
   χ=5.37, но реальная сеть даёт χ≈11.4. Расхождение 2×.
   → предсказания через аналитическую χ могут систематически промахиваться.
3. **Q18 не пойман численно.** Ловушка хрупкости выведена аналитически,
   но симуляция при A0=0.65 не показала эффект (A0 далеко от A*_eff).
4. **Нет эмпирики.** Ни одного реального датасета.

Эти четыре пункта — прямая повестка v5.2.
