# UAF v5.2 — Unified Adaptive Framework

**Фокус версии: ПЕРЕПРОВЕРКА всего конструкта на синтетических и реальных данных.**

Не развитие теории — валидация существующего. v5.1 построила замкнутую
теорию адаптивной устойчивости. v5.2 проверяет, описывает ли она что-то
за пределами породившей её модели.

---

## Мастер-уравнение

```
dA_i/dτ = α_s·C_ij·A_j·(1−A_i) + α_l·Π_i·PE_i·(1−A_i)
        + f·(1−A_i) − δ·(1−0.3·A_i)
```

- `A_i ∈ [0,1]` — closure_degree (главный параметр)
- `α_s=0.06, α_l=0.01, f=0.002, δ∈[0.008,0.015]`, `δ*≈0.0148`

---

## Что уже доказано (наследие v5.0 + v5.1)

Доказано **внутри модели**, аналитически + численно, CV < 0.003:

```
χ·A*_uns = δ/α_s = 0.200        ← топологический инвариант
χ·slope  = −16.61               ← инвариант наклона
χ = <k²>/<k>                    ← ненаправленные сети
χ = <k_in·k_out>/<k>            ← направленные сети
```

Финальная формула:
```
A*_uns(f, χ, Π₀) = δ/(α_s·χ + α_l) − (16.61/χ)·f − c_Π·ΔΠ₀
```

Обсерваторика из A(t): `AR1 → δ/δ*`, `γ₁ → тип типпинга`, `Var → sign(β)`.

Полный список — `docs/v5.1_findings.md`.

## ⚠ Главная проблема, которую решает v5.2

ВСЕ результаты v5.1 — теоретические/симуляционные на HMF (среднее поле).
- НЕТ проверки вне среднего поля (полная агентная симуляция).
- НЕТ эмпирической валидации на реальных данных.
- НЕТ операционализации (как мерить A, χ, δ из реального ряда).

---

## Три фазы v5.2

**Фаза 1 — синтетический краш-тест.** Держатся ли инварианты в полной
N-агентной симуляции (ABM), без приближения среднего поля? Если ломаются —
вся теория артефакт HMF. Самый дешёвый и самый информативный тест.

**Фаза 2 — мост операционализации.** Как извлечь A, χ, δ из наблюдаемого
ряда (обратная задача). Без этого моста фаза 3 невозможна.

**Фаза 3 — реальные данные.** Только после зелёного света фаз 1–2.

Подробности — `ROADMAP.md`.

## Принцип v5.2

> "v5.1 построила теорию. v5.2 проверяет её на земле."

Цель — не новые формулы, а ответ: правда ли старые формулы описывают
что-то реальное. Возможный исход — некоторые инварианты не переживут.
Это нормально и ценно. Отрицательный результат — тоже результат.

NPG ≤ 0 → отклонить модель в этом домене. Всегда.
