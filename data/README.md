# data/ — Датасеты для валидации

Сюда кладутся реальные и синтетические данные для Фаз 2–3.

## Структура
- `synthetic/`  — сгенерированные ABM-траектории (Фаза 1)
- `real/`       — реальные временные ряды (Фаза 3)

## Правила
- Каждый датасет → README с источником, единицами, известными типпингами
- Сырые данные не редактируются; обработка — отдельным скриптом
- Большие файлы не коммитятся в репо (только ссылка на источник)

## Кандидаты для Фазы 3
- Палеоклимат (окончания ледниковых периодов) — известные CSD-исследования
- C.elegans коннектом (302 нейрона, направленный) — Q22
- Экосистемные коллапсы (популяционные ряды)
- Финансовые кризисы (рыночные ряды перед коллапсом)
